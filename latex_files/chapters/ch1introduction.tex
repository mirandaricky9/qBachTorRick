\section{Problem Statement}
BitTorrent is a popular \ac{P2P} communication protocol that allows for file sharing, specifically in a decentralized manner. Sharing files in this manner is also known as ``torrenting''. Historically, critical features of BitTorrent have been tracked via \ac{BEP}, similar to that of PEP or Python Enhancement Proposal. For example, BEP 5 introduced the \ac{DHT} protocol, BEP 11 introduced Peer Exchange, and BEP 52 introduced SHA-256 based infohashes and Merkle tree hashing.
