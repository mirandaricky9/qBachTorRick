\section{Background and Problem Statement}
BitTorrent is a popular \ac{P2P} communication protocol that allows for file sharing, specifically in a decentralized manner. Sharing files via BitTorrent is also known as ``torrenting''. A torrent file is a file that contains metadata about files and folders that are to be distributed. The number of clients hosting a file are referred to as a swarm. Files are typically uploaded and hosted by one node initially and from there, multiple nodes can download the file and then proceed to host the file. This allows for an increased amount of resources regarding file hosting as the swarm grows. 

Historically, proposals and implementations of critical features of BitTorrent have been tracked via \ac{BEP}, similar to that of PEP or Python Enhancement Proposal. For example, BEP 5 introduced the \ac{DHT} protocol via Kademlia, BEP 11 introduced Peer Exchange, and BEP 52 introduced SHA-256 based infohashes and Merkle tree hashing.

Despite the various number of changes and revisions to BitTorrent protocols, the core routing algorithm of Kademlia, the \ac{DHT} used by BitTorrent, remains virtually the same. The main routing components include randomly generating IDs for each node, selecting relay nodes with closest XOR logical distance, and iteratively searching for relay nodes \cite{KademliaRouting}. If significant improvements can be made to the routing algorithm to allow for better performance, many applications using the BitTorrent protocol and by extension, their clients, would reap the benefits. 



\section{Project Objective(s)}
The goal of this project is to construct a prototype BitTorrent application and implement improvements found in recent literary works from authors investigating similar technologies related to file distribution. The primary objective includes improving the core routing algorithm of Kademlia using techniques mentioned in \cite{KademliaRouting} which looks at improving Kademlia for the \ac{IPFS} as opposed to BitTorrent. Additionally, we wish to explore methods that target file unavailability which continues to be a huge problem with BitTorrent-based applications.
