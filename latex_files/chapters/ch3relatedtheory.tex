\section{Requirements}
For this project, we will need access to LLMs, MLs, and NLP techniques that have been used for bot detection. Some of these models are free to use, such as GPT-4.5 from OpenAI but others will require licenses or subscriptions. We will require access to the Twibot-22 which is given to us free of charge via the researcher's GitHub repository. And lastly, in order to have better engagement metrics on the bot account for X, a subscription for X will be required as many suspected bot accounts are also verified for a boost to engagement.
\section{Timeline}
The timeline for this project will be done over a period of 16 weeks, from the months of August to December of 2026. Since there are four parts to the project, we will split them up into four-week blocks. 

The first set four weeks will focus on surveying the different methods and organizing based on best detection element. The second set four weeks will focus on applying those detection methods to the latest dataset, Twibot-22. This period will also involve setting up the environment to properly test on the dataset. The third set of four weeks will involve creating a bot via a GPT, specifically within the first two weeks of this block, and allowing it to interact with the platform for the remaining two weeks. For the last set of four weeks, while still collecting data from our bot, we will apply the methods of bot detection against our own bot with the data it generated.
